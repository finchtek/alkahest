# Contributing

Thanks for taking a look at the code.

**Pull requests aren't accepted at this time.** This keeps the license
situation unambiguous: every line of code here is owned outright by Finch Tek LLC
under the [PolyForm Shield license](./LICENSE), and accepting outside patches
without a Contributor License Agreement in place would muddy that. If that
changes in the future, a CLA process will be added here first.

What's welcome instead:

- **Issues** — bug reports, format requests, broken conversions. Please
  include the input/output format and, if possible, a sample file (or a
  description of one) that reproduces the problem.
- **Forks** — the license explicitly allows reading, modifying, and
  self-hosting your own copy for personal use. The one thing it doesn't
  allow is using this code (or a fork of it) to run a competing
  file-conversion product or service. See [LICENSE](./LICENSE) and
  [NOTICES.md](./NOTICES.md) for the exact terms.

If you want to report a security issue specifically, please don't open a
public issue for it — reach out via the tip jar/contact link on the site
instead so it can be fixed before it's public.
